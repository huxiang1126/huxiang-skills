# poster.html 里的模板

每个模板都是 `T.<name>(spec)`。spec 里有三部分：
- `t`：文案，来自 plan.py 的 LOOKS；
- `c`：这一套衣服的配色；
- `img` / `img2` / `img3` / `cut`：用到的图片和抠像。

| 模板 | 画面 | 什么时候用 |
|---|---|---|
| cover | 两行巨型压缩字，共用一个字号，全身抠像站在字前 | 每套第 0 拍；开场第一帧 |
| web | 网页导航式排版；两个词共用一个字号，人放在右边 | 同上，与 cover 交替用 |
| glass / clear | 纹理玻璃 / 同一构图的清晰版，配 3×3 网格标签和衬线斜体标题 | 第 8、9 拍，一对一起出 |
| split | 左边奶油色面板：衬线标题、小图、正文；右边整张照片 | 八分音符段 |
| half | 左边照片，右边色块配衬线标题 | 八分音符段，可换深色 |
| rows | 满版照片，三行字铺满宽度 | 八分音符段；开场前的快闪 |
| headtop | 色块底，两行大标题，照片窗口压在第二行上 | 八分音符段 |
| neon | 左边照片，右边荧光色面板：方形小图、粗体两端对齐正文 | 八分音符段 |
| navy | 深色面板里是亮色的两端对齐正文，右边照片 | 八分音符段 |
| profile | 浅灰底，黑白人像，左边黑色大字 | 八分音符段 |
| blackpage | 黑底，右上角黑白小图，两段右对齐正文 | 八分音符段 |
| white | 白底加导航，三行粗体，下方一条黑白照片 | 八分音符段 |
| bluefield | 电光蓝底，黑白照片块，大字贴住底边 | 八分音符段 |
| logo | 满版细节特写，大号 HU·X© 加标签 | 第 5 拍 |
| mirror | 深色纸纹底，标题加镜像标题，中间是黑白全身抠像 | 第 11 拍 |
| items | 大编号、单品清单（中英文）、一张照片 | 第 12 拍 |
| burst | 同一个框，十六分音符换照片，加帧号 | 第 13–15 拍 |
| gradient | 渐变底，抠像，大号衬线斜体地名 | 第 15 拍：下一套的预告 |
| massive | 黑底一行巨字，四张小图，栏文 | 结尾前 |
| lineup | 四套全身抠像并排，配中文单品名 | 结尾 |
| sign | 黑底落款 | 最后 1.75 秒 |

几条规矩：
- **标题统一走 `hst()`**：同组共用字号，同时受宽度和高度限制，可以贴上边或贴下边对齐。
- **小标签走 `lab()`**：Helvetica Neue Bold，15–17 px，大写。
- **正文**：Helvetica Neue 500，两端对齐；衬线用 New York，第二行斜体。
- **中文用 Noto Sans SC**，只用在单品名和落款上。
