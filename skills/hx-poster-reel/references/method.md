# ON FOOT：量到的数和改过的地方

## 参考
- **长度和节奏**：参考是 3.8 秒、5 fps 的 GIF，一共 19 张，每张停 0.2 秒。
- **出现过的版式**：巨型压缩字标题、衬线斜体、角落网格标签、色块对半、人像抠图站在大字前、黑白人像、镜像标题、纹理玻璃、网页导航式排版、黑底大字配小图和栏文。
- **抄什么**：只抄语法，不抄内容；参考的出处也不需要写进片子。

## 节拍（140 BPM 的 hip-hop）
- **网格**：拍长 0.4287 秒，半拍 0.21 秒。视频从歌的 11.877 秒开始，drop 落在视频的 3.43 秒。
- **drop 之前两小节没有 hi-hat**：每拍一张；玻璃转清晰用两拍；最后一拍按十六分音符快闪进 drop。
- **每 16 拍一套衣服**，重低音落在第 0、5、8、11、15 拍：

| 拍 | 放什么 |
|---|---|
| 0–2 | 大字加抠像，停住 |
| 2–5 | 每半拍换一张 |
| 5 | 细节，加 logo |
| 6–8 | 每半拍换一张 |
| 8 | 玻璃 |
| 9 | 清晰 |
| 10–11 | 每半拍换一张 |
| 11 | 镜像标题 |
| 12 | 单品清单 |
| 13–15 | 十六分音符快闪 |
| 15 | 下一套的预告 |

- **结尾**：4 拍的四套并排，歌停在最后一下重击上，接着黑底落款 1.75 秒。
- **剪点精度**：剪点按帧取整（30 fps），实测比低音起点早 0.03–0.04 秒，这个误差看起来是“在拍上”的。

## 素材
- 4 套 SKU，共 52 张图（街拍单图加九宫格切出来的格子）。
- 新增的 5 张放大一倍，每张 0.5 积分；抠图 12 个，每个 1 积分；合计 14.5 积分。

## 第一轮的毛病和改法
- **两行标题各自撑满宽度**：“ON”被放到巨大，把“FOOT”吃掉了。
  改法：同一组标题共用一个字号，按最宽的那行算，同时限制总高度，并贴住上边或下边对齐。
- **底部对齐的标题冲出画框**（TIED LOOSE、HIGH NOON）。改法同上，用 bottom 锚定加最大高度。
- **玻璃纹理像铁丝网**。改法：
  - 镜头拉近到脸，放大 1.7 倍；
  - 每格 21 px、斜 45°；
  - 每格里的像取反缩小（k = -0.75）；
  - 暗边降到 30%，高光点降到 46。
- **镜像海报用了半身抠像**，裁切的直边露出来了。改用全身抠像，脚伸出画面底边。
- **大字被人整个挡住**（SUEDE 和 & SUN）。改法：字只占左边 470 px，人放到 x = 790；字可以被挡一部分，不能被挡掉一整个词。

## 渲染
- **只能用浏览器排版**：PIL 没有字距调整（kern 对的差值实测为 0），所以海报走 HTML 加 headless Chrome（puppeteer-core）。
- **速度**：121 张海报先各出一帧约 8 秒；全部 516 帧约 45 秒；拼片约 6 秒。
- **只有停住的海报逐帧出**：按停住的帧数出图，照片层用 ease-out 从 1.0 慢推到 1.035。
