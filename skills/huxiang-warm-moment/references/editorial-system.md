# 温暖一刻：编辑与视觉系统

## 阅读运动

`带引号的标题命名感受 → 场景降低防御 → 经典思想回声提供支点 → 英文延长余韵 → 无标题小注把道理还给读者`

真正有效的不是“萌宠 + 名人名言”，而是用低防御的生活意象承载一组人人经历过、却不容易说清的张力。

## 五层可见文字

- 标题：6–16 个汉字，必须带中文双引号。
- 中文经典表达：1–3 行。
- English echo：8–28 词，1–3 行。
- 署名：作者或典籍、作品/章节，克制但清晰。
- 原创小注：35–80 字，不重复标题；默认不显示“给此刻的你”等模板标题。

标题优先容纳双面真相，例如“靠近 / 自由”“期待 / 落空”“疲惫 / 仍想负责”。英文承担呼吸和余韵，不写成说明书式翻译。

## 双色马克笔

只使用：

- 鼠尾草绿：`#7F9278`，浅标记底 `#DDE5DA`。
- 陶土橙：`#C87355`，浅标记底 `#F2D3C7`。

每张图只标 1–2 处，每处 2–6 个汉字或 1–4 个英文词。优先标记情绪转折词、关系词和可被记住的短语。标记从文字下半部穿过，保留手划的不完全整齐感，不做整块彩色标题框。

不要同时标标题、中文、英文三处；不要让两个颜色平均分配到每一个模块；不要增加紫、蓝、黄等第三种强调色。

## 字体与海报网格

默认使用三套互补字体，不用一套系统黑体从头排到尾：

- 标题：`Songti SC Black`，58px 起，最多两行。用宋体的纵向骨架和收笔建立海报主张感。
- 经典中文：`Songti SC Bold`，40px 起，最多三行。与标题同语系但降低一级。
- 小注正文与署名：`Heiti SC Light`，正文 29px 起、署名 21px 起。
- 小注只允许一个 2–8 字重点使用 `Heiti SC Medium`，其余保持 Light；不要整段加粗。
- 英文：`Baskerville Italic`，25px 起；缺少时退到 Georgia Italic 或 DejaVu Serif Italic。

macOS 默认字体文件为 `Songti.ttc`、`STHeiti Medium.ttc`、`STHeiti Light.ttc`、`Baskerville.ttc`；其他系统退到 Noto Serif CJK + Noto Sans CJK。不要把手写体用于长文，不要用卡通字体，不要让英文使用普通 Arial 破坏气质。

采用 8px 基线网格。顶部标题居中；照片全宽出血；照片以下所有中文、英文、署名与小注共享同一条左对齐线。模块间距按“原句紧、英文稍松、署名收拢、小注重新起段”的节奏组织。不要为了填满而无原则放大文字，优先调整照片高度、段间距和内容长度。

马克笔色块必须与字脚基本齐平，只穿过字的底部约 15–20%，不能横切字腰。加粗负责信息层级，马克笔负责视觉记忆，两者不要在同一个句子里反复叠加。

## 线稿点缀

只使用一个：`sun`、`cloud`、`cat`、`bird`、`sprout` 或 `none`。使用鼠尾草绿或陶土橙单色细线，放在下部留白，不压文字、不与照片主体争夺注意力。

- `sun`：恢复、松动、重新看见。
- `cloud`：含混、等待、允许情绪经过。
- `cat`：边界、自主、温柔但不归属。
- `bird`：离开、远方、自由。
- `sprout`：恢复、微小开始、仍在生长。

创伤、哀悼、疾病或严肃关系伤害默认 `none`，除非图标不会轻佻化内容。

## 视觉隐喻

让场景通过姿态和距离表演命题，而不是画出关键词。优先使用一个普通主体、具体动作、开放空间、自然光、可信材质和有限配色。至少考虑一个不含人物或动物的方案。

禁用默认套路：夕阳背影、咖啡杯、拥抱、眼泪、双手捧光、萌宠卖乖、奶油滤镜。只有当输入真的需要且构图有新意时才可使用。

## 4:5 版式

固定 `1080x1350`，但不固定照片高度：

- 顶部标题约 12–13%。
- 中部无字场景根据真实文字高度在 500–670px 之间动态变化。
- 下部先计算中文、英文、署名、小注和图标的真实高度，再把剩余空间还给照片。

白底、深色正文、克制灰色辅助文字。照片始终全宽出血，不通过改窄图片解决留白。英文与小图标补足视觉密度；小图标跟随文字块，不孤立钉在画布底部。不要靠放大所有文字填满画面。不要在图片上放 URL。排版必须确定性合成，不让图像模型直接生成中英文。

## 检查

1. 去掉文字，场景仍有情绪。
2. 去掉场景，标题、经典、英文和小注仍各司其职。
3. 经典不是装饰，英文不是重复，小图标不是卖萌。
4. 最终 PNG 的裁切、错字、标点、字号、行距、溢出、署名与配色全部过关。
